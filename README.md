# kubernetes-labs

A record of hands-on Kubernetes labs completed on Killercoda, 


## Coverage
Troubleshooting: 25+ scenarios (pods, nodes, kubelet, ETCD, 
  network policy, RBAC, DaemonSets, CronJobs, PV/PVC)
Architecture: Cluster upgrade, ETCD backup/restore, RBAC, secrets, logging
Storage: PV, PVC, StorageClass, volume resizing
Networking: Ingress, NetworkPolicy, CoreDNS, NodePort, ClusterIP
Workloads: Deployments, rollouts, rollbacks, ConfigMaps, secrets

## Why this format
These aren't done by AI. Each file documents what I 
observed, what i diagnosed, what decisions i made and depicts the intuition
I build through these around kubernetes clusters.
